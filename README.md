# Linear Algebra Notes in Python

This notebook collects the linear-algebra examples I used while learning NumPy and SciPy. It connects the mathematical ideas with small pieces of Python that can be run and changed interactively.

## Topics covered

- creating and reshaping matrices
- matrix multiplication
- eigenvalues and eigenvectors
- singular value decomposition
- vector and matrix norms
- orthonormal vectors
- sorting, conditional selection, and numerical comparison in NumPy
- saving matrix results for later use

## Running the notebook

Open `linear algebra/Linear algebra payam.ipynb` in Jupyter Notebook, JupyterLab, or Google Colab. The main dependencies are NumPy, SciPy, and Matplotlib.

These are personal study notes rather than a complete linear-algebra course. Some explanations are brief because the notebook was designed to support hands-on practice.
